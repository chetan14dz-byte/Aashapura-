AASHAPURA RAJPUTI RIWAAZ — Free starter website

WHAT'S INCLUDED
- Mobile-friendly jewellery storefront
- Search and category filters
- Shopping cart
- WhatsApp order handoff
- No card/bank details collected by the website

BEFORE PUBLISHING
1. Open index.html in a text editor.
2. Find: whatsapp: "91XXXXXXXXXX"
   The shop WhatsApp number is already set to +91 9667386868.
3. Find the `const products = [` section.
   Replace the three sample items with real product names, categories, prices and image URLs.
   Keep image URLs public HTTPS links. Do not publish customer/private photos.
4. Test by opening index.html on your phone or computer.

IMPORTANT LIMITATIONS
- This is a static, free starter site. It does not have a secure online admin account, central inventory database, automatic order dashboard, or payment gateway.
- Cart data stays in the visitor's browser. Orders are sent to the shop by WhatsApp only after the visitor taps the button.
- Do not add passwords, card numbers, UPI PINs or bank details to the website.
- For a public live site, publish these files using a free static host such as GitHub Pages. A free host subdomain can be used; a custom domain usually costs money.
- The owner must create and control the hosting account. Keep its password private and enable two-factor authentication.
